Atividade Prática – Publicar Aplicações Web

UC4: Transferência e Publicação de Projetos PWA

Aluna: Amanda Nicole Grabowsky Bongiovani

Data: 02 de setembro de 2025

Este site apresenta a atividade prática de publicação de aplicações web. O projeto foi desenvolvido como um PWA, pronto para funcionamento online e offline.

Objetivos da Atividade

  • Compreender o processo de preparação de arquivos locais para publicação em servidor web.
  • Identificar formatos, estruturas e tecnologias adequadas para exportação.
  • Realizar exportação e transferência do projeto para um ambiente de hospedagem (GitHub).
  • Desenvolver autonomia no processo de publicação e manutenção de aplicações web.
