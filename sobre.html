Desafios e Etapas

UC4 – Publicar Aplicações Web

Desafio e Problematização

Como organizar e preparar os arquivos do projeto para publicação?

R. Organizei os arquivos separadamente, porém dentro da mesma pasta.

Qual formato deve ser utilizado para enviar o projeto ao servidor?

R. Utilizei os arquivos originais (HTML, CSS, JSON, JS e imagens), mantendo a estrutura dos arquivos.

Quais ferramentas podem ser usadas para exportar e transferir?

R. Optei pelo GitHub, que permite publicar o projeto diretamente do repositório.

Como garantir que o site funcione corretamente após a exportação?

R. Testei todas as páginas, links e imagens no ambiente online, verificando que o PWA funcionava offline e que todos os recursos eram carregados corretamente.

Etapas da Atividade

  1. Organização do Projeto Local: Estruturar pastas (HTML, CSS, JS, imagens) e verificar links.
  2. Exportação e Publicação: Publicar no servidor gratuito (GitHub), testar todas as páginas e links.
  3. Documentação: Elaborar tutorial explicando o processo de exportação e publicação.
  4. Apresentação Final: Mostrar o site publicado e relatar os desafios enfrentados.

Documentação

  1. Organização do projeto local: Criei pastas separadas para HTML, CSS, JS e imagens, garantindo que todos os links funcionassem corretamente.
  2. Criação dos arquivos PWA: Desenvolvi index.html e sobre.html, adicionando manifest.json e service-worker.js para funcionamento offline.
  3. Publicação no GitHub:
    • Criei um repositório no GitHub.
    • Fiz o upload dos arquivos para o repositório.
    • Ativei o GitHub nas configurações do repositório.
    • Testei o site online e offline, garantindo que o PWA funcionava corretamente.
  4. Testes finais: Conferi imagens, links e botões para garantir que todas as funcionalidades estavam corretas.

Conclusão

Esta atividade permitiu compreender todo o fluxo de publicação de uma aplicação web, reforçando a importância da organização de arquivos, uso de ferramentas de hospedagem e desenvolvimento progressivo com PWA.
